# 贴钻项目术语（2026-09-29）

来源：Owner 当日两段原话；右栏为本轮设计裁定的用法，尚未实现。

| 词 | 约定含义 |
| --- | --- |
| 素材集合 | 系统内已建立的钻组合；集合成员是标准钻的弱引用，不是项目真值。 |
| 项目钻清单 | 项目已明确引入的钻清单；从集合展开或经 MCP 追加，按项目版本化保存。 |
| 复制/展开 | 选集合时把当时成员及钻规格快照写入项目；集合后续变化不自动同步。 |
| 已引入 | 钻的 `stoneRef` 出现在项目钻清单中；不等于全局库独占或库存锁定。 |
| 未引入警告 | 图层策略使用库内钻但该钻不在项目清单时的 lint warning；用户确认后可通过 MCP 追加消除。 |
| 库外钻 | 全局标准库没有有效 `stoneRef` 的钻；不能由项目 MCP 工具创建。 |
| 备料参考量 | 集合 `quantity` 的原有含义；不构成可用量上限或库存承诺。 |
| 任务导出 | 从当前任务排钻真值产出目标图片的 SVG、PNG、BOM；区别于现有只出 JSON 的 `task.export` 和独立资源的 `studio.export`。 |
