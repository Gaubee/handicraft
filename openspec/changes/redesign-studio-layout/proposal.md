## Why

上版三轮视觉迭代后 Owner 仍不满意（「布局需要完全设计」）。PM 诊断（记分卡 Journey 5/10 触发硬规则）：主区为滚动长列，画布 45vh 嵌于其中——滚到导出条时画布离屏，调密度看不到反馈窗口；答案位（共 N 钻）随滚动消失；CompareGrid 常驻五卡把低频决策（策略对比）做成家具，迫使画布让位。结构性问题修补无效，须重排。

## What Changes

- **方案 A「舞台+检查器+胶片带+对比模式」**（vs 方案 B 双栏常驻对比，两稿对比与推荐理由见 PM §3.4，[议题4] 待 Codex 终裁）：
  - 画布常驻舞台（flex 填充上下文条/胶片带/状态条之间全部剩余空间，参数改动即时可见）
  - 右侧 320px 上下文化检查器（选中块详情置顶；无选中=全局态折叠组）
  - 五策略降为胶片带 chips（点击=导出策略唯一真源写入，hover 浮出预览）
  - 真对比升级为全屏覆盖层模式（五栏大图 + A/B 滑动，Esc/点卡退出）
  - 状态条常驻：共 N 钻 + 校验徽标 + BOM 摘要 + 导出组 + 送精修；违规时浮出修复直达
- **CompareGrid 拆分**：→ StrategyFilmStrip + CompareOverlay；预览模式控制（纯钻/叠稿/叠原+透明度）迁至画布上下文条；修复开关就近化到状态条违规浮出。
- **移动端**：结构保留（画布优先+参数抽屉+选中块半屏抽屉），画布从 60vh 定值改 flex 填充，胶片带=横滑 chips，对比模式=全屏 Sheet。

## Non-Goals

- 不动 studio store 计算与状态语义（origin 增 'library' 等属 add-asset-library；本 change 仅视图层重组）
- 不改引擎与 worker 管线
- 不做键盘快捷键 1-5 切策略（P1）
- 视觉 token/风格方向不在本 change（结构稿；视觉执行另走候选流程）
