# 设计：PS 图层面板复刻+父层产钻语义修复

## §1 产钻语义（Owner 裁定）

```
可贴钻节点 = 叶子节点（children.length === 0）
中间节点（组）恒不产钻、不产块、无策略指派入口
```

- design.ts producesBlockOf 删 drillWorthy 分支；策略设计 prompt 的「可贴节点清单」随之只列叶子。
- workbench setStrategy 校验：对有 children 的节点 typed 拒（params-invalid 同族面：`node-not-leaf`）。
- 既有数据兼容：execute/gems 读面不炸——父层旧指派在读面降级标注「已失效（组不产钻）」；execute 重算时跳过父层指派（不产块）。
- demo 映射：小丑（父层）移除指派；producing 覆盖断言=叶子集。

## §2 PS 图层面板规格（左栏重写）

参照 Photoshop 图层面板逐项：
1. **排序**：顶部=最上层（z 序顶部）——树前序的逆序渲染（父先子后=父在底；面板首行=渲染最后=最上层）。根「画布」行=背景层（v4 已定），固定面板最底行。
2. **行结构**（单行高度~28px）：
   - 眼睛图标（显隐——组隐藏=子树全隐）
   - 缩略图（~32×32，真实抠图内容；组=子层并集缩略或组图标+子层拼合——首版用子层并集 bbox 的原图缩略）
   - 名称（双击进入重命名；Esc/Enter 收尾）
   - **fx 徽标**（有钻布局的叶子行：小钻图标+颗数微标；点击=右栏滚到钻区）
   - 锁定图标（锁定层显示）
   - 选中=高亮蓝底（单选；shift 多选后续波）
3. **组行为**：展开三角；折叠=只显示组行；组行缩略=子层内容拼合示意。
4. **底部操作条**（PS 式图标条）：拆分层（当前选中叶子）/删除/展开全部/收起全部。
5. 顶部条：筛选/搜索留位（后续波）。
