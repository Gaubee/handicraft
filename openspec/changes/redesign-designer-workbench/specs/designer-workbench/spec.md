# 设计师工作台重写能力 Delta（PARKED 占位——Owner 确认后细化）

## ADDED Requirements

### Requirement: 设计师工作台自由创作模型（占位，待确认后细化）
设计师工作台 MUST 以空白画布为默认起点（图片仅作参考底图），自动排布 MUST NOT 作为默认入口；钻的放置/移动/旋转 MUST 为画布直接操纵；图层 MUST 支持合并且无范围（mask）语义、不支持自动填充。
#### Scenario: 空白起步（占位）
- **WHEN** 用户从素材库选图或新建进入设计师工作台
- **THEN** 画布只有参考底图（可调透明度/可关），无任何预生成钻；自动排布仅作为显式工具可调用
