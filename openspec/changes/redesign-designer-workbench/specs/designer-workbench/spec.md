# 设计师工作台能力（designer-workbench）Delta — redesign-designer-workbench

## ADDED Requirements

### Requirement: 设计师工作台自由创作模型
设计师工作台 MUST 以逐钻微调为一等公民：钻的放置/移动/旋转/改径/改色/改形 MUST 为画布直接操纵（手势 + 属性面板数字 + 快捷键三通道并存）。新建或选图进入后画布 MUST 仅有参考底图与零颗钻；任何自动排布 MUST NOT 作为默认入口或选图副作用执行——算法能力仅以显式「智能排布」工具存在。设计师工作台的图层 MUST NOT 有范围（mask）概念、MUST NOT 提供自动填充。

#### Scenario: 选图后零钻
- **WHEN** 用户经「选图新建」从素材库选图（或上传）进入设计师工作台
- **THEN** 画布呈现该图作参考底图，文档钻数为 0，无任何计算/进度在途
#### Scenario: 无隐式算法入口
- **WHEN** 用户浏览设计师工作台全部入口与空态
- **THEN** 不存在任何未经显式点击即生成钻的路径（旧「快速排稿」入口已退役）

### Requirement: 竖排工具栏与四区界面
桌面界面 MUST 为类 PS 四区布局：左侧竖排工具栏（选择/画笔/橡皮/抓手/缩放五工具 + 吸附开关，tooltip 标注快捷键）、居中画布、右侧面板列（上属性面板、下图层面板，可折叠）、顶部文档栏（文档名/未保存徽标/智能排布…/撤销重做/保存）、底部状态栏（画幅读数/缩放比/钻数/当前规格码/间距徽标）。属性面板 MUST 为选中对象属性（PS Inspector 语义），呈现空态/单选/N 选三态，批量修改 MUST 为单个撤销组。

#### Scenario: 竖排五工具
- **WHEN** 桌面宽度进入设计师工作台
- **THEN** 左侧为竖排 icon 工具栏，含选择(V)/画笔(B)/橡皮(E)/抓手(H)/缩放(Z)五项与吸附开关，无其他工具
#### Scenario: 属性面板 N 选混合值
- **WHEN** 选中 3 颗直径不同的钻
- **THEN** 属性面板标题显示「3 颗已选」，直径字段显示混合值占位「—」，改写公共字段时一次撤销恢复全部原值

### Requirement: 逐钻选择与拖移
选择工具 MUST 支持：单击单选、Shift+单击加/减选、空白拖拽框选（相交判据 = 钻外接圆，仅收集未锁定层的钻）、Esc 清空。拖拽选中钻 MUST 移动选集（松手才写入、单撤销组）；Shift 拖拽 MUST 约束水平/垂直主轴；Alt+拖拽 MUST 复制选集并拖动副本（副本完整语义：新 id 走手工钻自增、origin='manual'、blockId=null、moved 重置、归属当前目标层——跨层选集的副本统一归当前层；原钻原位且归属不变）。移动 MUST NOT 因间距冲突被阻断（间距违规仅导出硬阻断）。

#### Scenario: 框选跳过锁定层
- **WHEN** 图层 A 锁定、图层 B 未锁定，用户框选覆盖两层钻
- **THEN** 仅图层 B 的钻进入选集
#### Scenario: Alt 拖拽复制
- **WHEN** 按住 Alt 拖动一颗选中钻到新位置松手
- **THEN** 原钻保留原位（归属不变），新位置产生一颗同规格副本（新 id、origin='manual'、blockId=null、moved 重置、归属当前目标层），一次撤销可同时移除副本

### Requirement: 变换手柄
单颗选中钻 MUST 显示变换手柄：旋转柄（拖拽绕钻心旋转，实时度数读数，Shift = 15° 步进）与直径柄（拖拽连续改直径，实时 mm 读数，不强制吸附档位；值域 MUST 为 (0, 50] mm，越域或非法输入 MUST 回滚至本次会话前值，一次拖拽会话 MUST 为单个撤销组）；圆形钻 MUST NOT 显示旋转柄。多选 MUST NOT 显示变换手柄（多选变换经对齐/分布与批量属性）。手柄、属性面板数字输入、快捷键步进三通道 MUST 写同一更新面。

#### Scenario: 拖拽旋转带步进
- **WHEN** 用户拖动方形钻的旋转柄，按住 Shift 停留
- **THEN** 角度按 15° 步进吸附，气泡显示当前度数；松手后一次撤销可回到原角度
#### Scenario: 圆钻无旋转柄
- **WHEN** 单选一颗圆形钻
- **THEN** 仅显示直径柄，不显示旋转柄

### Requirement: PS 惯例键位与命令同源
键位 MUST 遵循 PS 惯例并全表落地（design §3 分组表）：工具单键 V/B/E/H/Z 与空格临时抓手；⌘Z/⌘⇧Z（⌘Y）撤销重做；⌘C/⌘X/⌘V（粘贴原位偏移一格）；Delete 删除（确认弹窗）；⌘D/Esc 取消选择；方向键三档微移（1px / Shift=pitch / Alt=0.1mm）；[ / ] 旋转 15°（Shift=5°）；⌘+/⌘-/⌘0/⌘1 视图；⌘⇧N 新建图层、⌘E 向下合并、⌘[ / ⌘] 与 ⌘⇧[ / ⌘⇧] 层排序；⌘S/⌘⇧S 保存/另存。输入控件聚焦时 MUST 放行全部快捷键。快捷键、右键菜单、面板按钮 MUST 收敛到同一命令总线（禁第二实现）。

#### Scenario: 工具单键切换
- **WHEN** 画布聚焦时依次按 B、E、V
- **THEN** 当前工具切换为画笔、橡皮、选择，进行中的框选与笔刷读数被丢弃
#### Scenario: 旋转步进键
- **WHEN** 选中一颗方形钻按 ]
- **THEN** 该钻顺时针旋转 15°；按 Shift+] 为 5°；连续按键在一个按键会话组内（一次撤销恢复整组）

### Requirement: 指针交互清单
画布指针交互 MUST 覆盖 design §2 清单：滚轮以光标为锚缩放（10%–1600%）、空格或中键随时平移、双击空白在 100%/适配间切换、双击钻定位属性面板、右键按选中态/空态弹出上下文菜单（复制/剪切/粘贴/删除确认/对齐分布（≥2/≥3 显隐）/移入图层/改规格；空态：粘贴/智能排布…/画幅设置…/适配/100%）。图层面板行 MUST 支持：单击选层（当前层 = 新钻与智能排布落点）、双击层名重命名、眼睛显隐、锁锁定、Alt+点眼睛孤立显示、拖拽排序。

#### Scenario: 空格临时抓手
- **WHEN** 画笔工具激活时按住空格拖动画布
- **THEN** 视图平移且不落钻；松开空格回到画笔工具
#### Scenario: 右键菜单对齐显隐
- **WHEN** 分别以 1 颗、2 颗、3 颗选中钻右键
- **THEN** 1 颗时无对齐/分布子菜单，2 颗时出现对齐无分布，3 颗时对齐与分布均在

### Requirement: 多图层系统
文档 MUST 支持任意多钻石层：建层（⌘⇧N/面板）/命名/显隐/锁定/排序（数组序 = z 序，渲染与 SVG/PNG 合成序按 z 序派生；BOM 行序 MUST 仍按规格×颜色聚合、MUST NOT 随层序重排；真源 gems 数组序 MUST NOT 因面板排序重写）/成组移动（选集拖移不改归属）/移入图层（标签标当前层、禁用态按真实归属、单操作撤销）。锁定层的钻 MUST 不可选中、不可编辑、橡皮命中 MUST 跳过。删除含钻图层 MUST 弹确认（提示钻数）；最后剩余一层 MUST NOT 可删。层数据 MUST 持久化进 .gemdoc（schema v3；层记录含可选 opacity，缺省 1.0）。每颗钻的归属（layerId）MUST 在 v3 记录中逐颗携带。

#### Scenario: 锁定层保护
- **WHEN** 图层 A 锁定后用户尝试框选、拖移、橡皮擦除其钻
- **THEN** 选择与编辑均不可作用，橡皮命中跳过该层钻
#### Scenario: 排序不改真源序
- **WHEN** 用户拖动「图层 1」到「图层 2」之上并保存后重开
- **THEN** 面板 z 序与视觉叠放为新序，文档内钻数组序与各钻 id 不变，BOM 行序不变

### Requirement: 图层合并
图层 MUST 支持合并：⌘E = 当前层并入下一可见未锁层；面板指定目标层合并亦须支持。合并 MUST 将源层全部钻归属改写为目标层并删除源层记录；因层不持有规格属性，不同规格的钻 MUST 自然共存于合并后图层（无调和/无转换）。合并 MUST 为单个可撤销操作（一次撤销恢复源层与全部归属）。

#### Scenario: 规格混合合并
- **WHEN** 图层 A（SS10 圆钻）与图层 B（SQ35 方钻）合并
- **THEN** 合并后单层同时含两种规格钻，BOM 按规格×颜色分别统计
#### Scenario: 一次撤销合并
- **WHEN** 用户执行 ⌘E 合并后按 ⌘Z
- **THEN** 源层记录与全部钻的原归属一并恢复

### Requirement: 参考底层
文档 MUST 含钉底参考底层（不可删、不可排序、无锁定）：三源（数字油画快照 / 参考原图 / 分块描线——按文档来源呈现）MUST 各自持独立可见性与独立透明度（每源 {visible, opacity}）；钉底行眼睛为各源可见性之聚合（派生态，点击全开/全关）。空白起步文档的参考底图 MUST 以素材库资产引用承载（内容不可变契约保持）。

#### Scenario: 透明度实时调整
- **WHEN** 用户拖动「参考原图」源的透明度滑杆
- **THEN** 该源底图透明度实时变化，可降至全隐（画布仅剩钻面），其余源与钻面不受影响
#### Scenario: 描摹工作流
- **WHEN** 选图新建后调低底图透明度并以画笔沿图落钻
- **THEN** 钻在半透明底图之上可见可调，保存重开后底图与源级透明度设置保持

### Requirement: 隐藏层导出口径
设计师工作台隐藏层 MUST NOT 参与导出（SVG/BOM/PNG）与统计明细。导出钻集 MUST 经唯一可见层投影（documentService.projectVisibleGems(doc)，按层 visible 过滤）产生：SVG/BOM/PNG 与导出前校验 MUST 消费同一投影钻集，直接调用导出 API MUST NOT 绕过该投影（裁剪在 service 投影面，不在 UI 层）；导出门（engine exportGate）契约保持零改动（调用方钻集口径）。锁定 MUST NOT 参与投影过滤（锁定≠隐藏：锁定层可见即导出）。可见钻集的间距与缺资产校验 MUST 仍走同一导出门（投影不豁免校验）。状态栏总量 MUST 按「含 N 隐藏」口径显示；存在隐藏层时导出确认 MUST 显式注明「不含 N 个隐藏层」（显式裁剪，非静默）；取消确认 MUST NOT 产出任何产物。此口径与排钻工作台（隐藏仍导出）为登记过的分模块分叉，随产品模型 v6 升版固化。

#### Scenario: 隐藏层导出提示
- **WHEN** 隐藏含 200 钻的图层后导出 SVG
- **THEN** 导出确认注明「不含 1 个隐藏层」，产物与 BOM 不含该层钻，状态栏仍显示「含 1 隐藏」
#### Scenario: 取消确认零产物
- **WHEN** 存在隐藏层时导出 PNG，在确认弹窗点「取消」
- **THEN** 无任何文件写出，文档与磁盘状态不变
#### Scenario: 锁定层仍导出
- **WHEN** 锁定一枚可见图层后直接经导出 API 导出 BOM
- **THEN** 该层钻仍出现在产物与 BOM 中（锁定≠隐藏，不参与投影过滤）

### Requirement: 空白起步与画幅锚定
新建流 MUST 提供三入口：选图新建（主）/ 空白新建（缺省画幅，可后改）/ 打开（.gemdoc 与 .gemproj 重放）。选图新建画幅 MUST 默认锚定参考图尺寸（缺省锚 2.5 px/mm，锚来源显式标识）；画幅 MUST 可经状态栏读数弹出的设置面板修改（宽/高 mm 与 px/mm，修改后锚转为 declared），新建时 MUST NOT 强制弹窗。

#### Scenario: 画幅缺省锚与改声明
- **WHEN** 选图新建（800×600px 图）后查看状态栏
- **THEN** 画幅读数 320×240mm 且标注「缺省锚」；改为 300×300mm 后标注消失（declared），导出按声明值物理正确

### Requirement: 旧档兼容
既有 .gemdoc（含自动排稿产物）MUST 可打开继续编辑：装载时内存迁移——全部钻入默认钻层「图层 1」（origin/blockId 原值保留，layerId 逐颗携带）。旧固定四层 MUST 按逐字段映射无损转换（每字段原值直传）：数字油画层（visible/opacity）→ 参考底层 painting 源（原值）；参考原图层 → reference 源（原值）；分块描线层 → blocks 源（原值）；旧钻面层 visible/opacity → 新钻层 visible/opacity（原值）。v3 序列化 owner 为 projectFile.ts 的 gemdoc v3 schema（唯一序列化出口，不新增第二格式真源）。保存 MUST 升级为 v3（formatVersion=3，单向版本门，MUST NOT 回写 v2）；v3 序列化 MUST 满足 serialize→parse→serialize 字节等价；未知或更高 formatVersion MUST 拒读并显式报错。打开旧档 MUST 一次性提示「已从旧版格式升级」。

#### Scenario: 旧档打开迁移
- **WHEN** 打开含 1200 颗自动排稿钻与固定四层的 v2 文档
- **THEN** 全部钻位于「图层 1」可逐颗编辑，数字油画与参考原图成为参考底层两个源（各自保持原可见性与透明度），toast 提示升级
#### Scenario: 旧层显隐透明组合无损
- **WHEN** 打开数字油画 30% 透明可见、参考原图 80% 透明、分块描线隐藏、钻面 50% 透明的 v2 文档
- **THEN** 迁移后 painting 源 {visible:true, opacity:0.3}、reference 源 {visible:true, opacity:0.8}、blocks 源 {visible:false, opacity 原值}、钻层 {visible:true, opacity:0.5}，保存重开后全部一致
#### Scenario: 保存升版往返
- **WHEN** 迁移后的旧档保存再重开
- **THEN** 文档为 v3（formatVersion=3），图层归属/参考底层各源 visible 与 opacity/钻层 opacity/画幅锚与保存前一致（round-trip 等价，无未声明漂移）
#### Scenario: 高版本拒读
- **WHEN** 打开 formatVersion 高于 3 的 .gemdoc
- **THEN** 拒绝装载并报「不支持的文档版本」，不进入部分装载状态

### Requirement: 智能排布工具
原「快速排稿」MUST 更名并工具化为「智能排布」：入口为顶部文档栏命令按钮（带省略号），无参考底图时 MUST 禁用并提示；点击 MUST 弹参数小窗（策略/基础规格/间距/密度），执行 MUST 复用既有计算链并可将进度与取消；结果钻 MUST 并入当前图层（单撤销组）；与既有钻间距冲突的结果钻 MUST 丢弃并在结果行显式报数（「并入 N 颗，跳过 M 颗冲突」），MUST NOT 静默丢钻。

#### Scenario: 结果落当前层可撤销
- **WHEN** 当前层为「图层 2」，执行智能排布
- **THEN** 结果钻全部归属图层 2，按 ⌘Z 一次即整体移除
#### Scenario: 无底图禁用
- **WHEN** 文档无参考底图
- **THEN** 智能排布按钮禁用，tooltip 说明「需要参考底图」

### Requirement: 笔刷与规格
画笔 MUST 按当前规格落钻（形×尺寸×色来自规格选择器，数据源为 sys-shapes 钻形资产目录），起笔-移动-收笔连线等弧长补钻，落钻冲突拒画闪红、MUST NOT 自产间距违规；橡皮命中即删且 MUST 跳过锁定与隐藏层。吸附开关（格位/自由）MUST 作用于落点：格位 = 当前规格 pitch 六方格位，切换规格时格距随 pitch 重算。一次笔迹 MUST 为单个撤销组；单次笔迹超 2000 钻 MUST 拒绝执行并提示。自定义钻形 MUST 经校准向导入库后可用；笔刷面 custom 形判据 MUST 为「必带 assetId」（替换内置五形白名单），且放宽 MUST 同时落地 asset 解析（assetId → sys-shapes 资产 resolver）、物化携带 assetId 与资产缺失（missing-asset）拒画报错——MUST NOT 只放宽 UI 判据。

#### Scenario: 规格跟随与吸附重算
- **WHEN** 规格选择器由 SS10 切换 SS16 后落钻（吸附开）
- **THEN** 新钻为 SS16 物化，吸附格位按 SS16 pitch 重算，连续笔迹一次撤销
#### Scenario: 橡皮跳锁定层
- **WHEN** 橡皮擦过锁定层与未锁层重叠区域
- **THEN** 仅未锁层的钻被删除

### Requirement: 移动端降级
移动端 MUST 降级为：底部工具条（选择/画笔/橡皮/撤销/重做/吸附开关）、右侧面板收为底部抽屉（属性/图层分段）、触摸手势映射（单指 = 工具行为、双指捏合缩放与拖动平移、长按 = 上下文菜单）、画幅与缩放读数并入顶栏。桌面四区 MUST NOT 因移动端适配受损。

#### Scenario: 双指导航
- **WHEN** 移动端画笔工具下双指捏合与拖动
- **THEN** 视图缩放平移且不落钻；抬指后画笔工具继续可用

### Requirement: 设计师工作台命名与术语
代码与界面文案中「专家工作台」MUST 更名为「设计师工作台」（桌面 Tab、toast、引导、注释、测试断言全库一致），移动端短名 MUST 为「设计」；「快速排稿」MUST 更名为「智能排布」（旧词入术语表禁用映射）；「送精修」动作名与交接通道 MUST 保持不变；术语表与产品模型 MUST 随本 change 升版（词条更名、新词条、硬规则 6/9 分模块口径修订）。
