# Design: 主体分割与多元贴钻内核

> 决策源：`owner-directive-20260924.md`（Owner 原话冻结）。本文是工程化展开，冲突处以原话为准。

## 0. 冻结红线

- 「主体」= 值得强调/值得贴钻的内容（黑色背景/灯光/脸蛋类=排除节点）。
- 识图=VLM 先行 + SAM3 迭代语义抠图；圈选是**补充微调手段**（用户标记强调/排除），不再是主驱动。
- 贴钻策略每图层各异；统一硬算法仅为基础几何族之一。
- Agent 对话层=策略层（图层级）；单钻微调只在设计师工作台。
- 模型推理只在 macmini（站级指令）；引擎零改动——一切策略输出 Gem[] 过引擎校验门。

## 2. 迭代停止判据（确定性，适配层计算）

1. **物理尺寸**：节点有效内容（mask 面积开方）≤ `K × maxGemDiameterMm`（K 默认 2.5——钻 2-5mm ⇒ ~5mm×5mm 量级，与原话对齐；随钻规格表取值）。
2. **颜色容差**：节点内 Lab 色方差 ≤ 阈值（天空/草地类大范围平色⇒停）。
3. **模型自评**：SAM3 提示返回无新实例/低 score ⇒ 该分支停（更佳路径，实测校准）。
4. **硬顶**：最大迭代数（默认按画布面积标定）+ 全局节点数上限。
后续轮 VLM 复入位：S3 循环参数 `vlmReentry: boolean`（默认 false，Owner 中立待实测）。

## 3. ObjectTree 工件 schema（核心新工件）

```ts
interface ObjectNode {
  id: string;                 // 全树唯一，即引擎 blockId（同寻址空间）
  objectName: string;         // 中文语义名（路灯·杆 / 路灯·灯头 / 柳树·枝条）
  category: string;           // VLM/SAM3 类别（structure/foliage/face/light/…）
  mask: Mask2D;               // 与引擎 Block.mask 同构
  parent: string | null;
  children: string[];
  effectiveMm: number;        // 停止判据数据（有效物理尺寸）
  labVariance: number;        // 停止判据数据（色容差）
  drillWorthy: boolean;       // 排除开关（灯光/脸蛋=false；LLM 建议用户可改）
  origin: 'vlm+sam3' | 'manual-lasso' | 'auto-color';  // 来源（一键模式=auto-color）
}
```

树持久化为任务产物 blob；S6-S8 全部寻址 `node.id`。

## 4. 贴钻策略四类

### 4.1 参数化几何族（纯 TS，参数模型冻结可校验）
- 既有五策略（hex-thin/hex-pitch/poisson/hybrid/cvt）+ 新几何形状：星形射线 `{center, rays, initialAngleDeg, density}`、心/方/圆/矩/椭圆/螺旋（各自参数 schema）。预览确定（同参同果），Zod 校验。

### 4.2 语义拟合族（参数极简+拟合算法重）
- 纹理贴图法：亮暗部二分（Lab 亮度阈值在节点内自适应），参数 `{density, target: bright|dark|both, mode: scatter|flow}`——「柳树顺枝条」= flow 模式沿亮度梯度线；
- 柔和曲线：节点中轴/骨架（距离变换脊线）+ 沿线贝塞尔布钻；
- 花形：节点内极坐标分解（花心=距心最近聚类核，花瓣=角度扇区）。
- 共同点：难全参数化 ⇒ 参数≤5 个 + 拟合算法吃重（Owner 原话「强行做参数预设有点够呛」）。

### 4.3 排除族
`drillWorthy=false` 节点跳过（不产 Gem；BOM 中明示「未贴区域」）。

### 4.4 自由代码族（Owner 倾向的模式，重要度最高）
- **形态**：LLM 生成 JS 代码片段（策略工件携带 `source`），沙箱执行产出 `Gem[]`。
- **沙箱（首版 JS）**：daemon 内 worker 隔离；无网络/无 fs/无 import；注入 API 面=「节点 mask+画布物理标度+钻规格表+几何函数库（dist/fit/极坐标/骨架/OpenCV-wasm 子集按需）+Rand(seed)」；CPU/时间有界；**输出 Zod 校验必须为合法 Gem[]，然后强制过引擎校验门（最小间距/exportGate）——不合格即策略失败回 LLM 重写（有界重试）**。
- **确定性**：同代码+同 seed 可回放（审计/重跑）。
- Python 备选：调研项（numpy/opencv 生态强但跨机执行面）——JS API 面不够用时开，桥槽位预留 macmini。

## 5. LLM 策略设计器（S6）

- 输入：ObjectTree JSON + 钻规格表 + 风格提示词（skill 层可定义艺术家风格——多版本候选为后话，接口 `styleId` 预留）。
- 输出：`StrategyAssignment[]{nodeId, strategyKind, params | codeSource, rationale}`——proposal 工件，走授权桥（approved-mutation：strategy.apply 全量入桥）。
- 可无视觉（纯文本决策）；VLM 复核为可选进阶。

## 8. 测试门

- 停止判据确定性单测（构造已知尺寸/色方差节点）。
- ObjectTree↔Block 适配等价（mask 逐位/寻址一致）。
- 四类策略各≥1 真实 fixture：星射线（参数断言）、纹理亮暗（目标区域命中）、排除（零 Gem）、自由代码（合法 Gem 过门+非法输出被拒+同 seed 回放）。
- 全链：分析→抠图(mock 桥)→树→策略→合并导出；一键模式回归不变；引擎零改动收据。

## 9. 概念验证实验反馈（2026-09-24，experiments/multistrat-spike-20260924）

四客户参考图全链实测（24 推理/83 实例/19 树节点/七类策略/引擎双门 0 违例）+ vision 独立判读。**证实**：多策略肉眼可辨、排除执行干净（overlay 零钻）、柔和曲线最出效果（缎带顺褶皱）、自由代码过门可行、六边形小件质感好。**回流修正**（按影响排序）：

1. **色彩塌缩（最大硬伤）**：每节点 1-2 个平色——白花→灰、绿叶→橙、条纹帽→单红（ΔE 42.2）。修正：节点内**子调色板量化**（每节点 k=2-4 子色）+ 起步色板扩容——§4.1/4.2 全族适用，新增设计项。
2. **覆盖完整性判据（新）**：未拆区（花茎/包装/彩球/领结）留白破构图——S3 迭代循环必须显式检查**未分配区域**：要么继续拆、要么显式排除，不允许默认悬空。
3. **掩码外溢**：beard 类语义过宽（压脸/手/膝花，15% 丢弃白壕）——掩码精修 pass（腐蚀/边界收缩）+ part-whole NMS（已登记 P4.3 提前）。
4. **几何策略最小尺寸门（新）**：星射线 16 颗读不出星形——参数化几何族加「节点有效尺寸≥策略可读下限」守卫，不足降级 hex。
5. **停止判据权重修正**：软判据（尺寸/色容差）卡通稿 0/19 触发，实际停止器=「模型不再返回新实例」——§2 判据 3 为主、1/2 为辅（记录用）。
6. **密度标定（新）**：客户成品全覆盖密铺 vs 实验 721-1128 颗稀疏——策略默认密度按客户成品密度反推标定。
7. **对照基线澄清**：四图为插画原稿（非实体钻画照片）——对照性质=原稿 vs 钻点渲染。
8. 工具线小修：annot 顶行裁切/标签防叠压、treeview 盒布局防碰撞。

## 10. 纹理填充 v2 实验反馈（2026-09-24 晚，experiments/texture-spike-20260924）

两技法互证+vision 判读结论：**机械感消除确认**（A/B 两版零行列对齐，hex 基线全面落后）；**A（ETF 流线）方向跟随双证**（视觉：胡须 S 波链/雪橇卷纹环链/缎带放射弧；程序：切向夹角 18-32° vs 各向同性 45°）；**B（加权 Voronoi）满铺零孤岛**、四图零翻车。回流修正：

1. **策略路由定稿方向**：B 打底 + A 特征描线的按节点混合——线主导节点（发须/卷纹/枝条/缎带/轮廓）走 A，面状/渐变节点（脸颊/背景/水彩晕染/花瓣填充）走 B；hex 族加风格门控（默认关，卡通 ~1%——Owner 原话）。
2. **受限 Lloyd 松弛器**=合并 A/B 优点的首选单点投资（覆盖 0.9+、方向损失 <5°）。
3. **色彩族完整性（新硬门）**：ebdc 红族在 white 渲染缺失（分割未生成红色板节点——管线 bug 非策略 bug）——识图迭代加「色彩族完整性」检查（原图显著色系必须在节点调色板中有着落）；验收一律以 drills-white 为准（overlay 路径会掩盖）。
4. **多色空间一致性**（纸屑感）为下一攻关点（空间聚类约束的子色分配）。
5. 白钻-白底对比度：产品渲染底色需非纯白（浅灰/画布纹理）。
6. 本轮脸区照贴=Owner「排除搁置」指令的执行（crop 标签为上轮残留，已澄清非规格冲突）。
