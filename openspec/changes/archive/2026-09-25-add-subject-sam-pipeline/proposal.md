# Proposal: 主体分割与多元贴钻内核（VLM+SAM3 迭代抠图 → object-tree → 策略化贴钻）

## Why

**Owner 2026-09-24 内核定调**（原话全文冻结于 `owner-directive-20260924.md`，本文件不得改写其语义）：

1. **"主体"= 值得强调/值得贴钻的内容**（非语义主客体）：黑色背景不贴、灯光不贴、脸蛋不贴（破坏质感）。
2. **识图=VLM 先行 + SAM3 迭代语义抠图**：视觉大模型先分析图内元素（草地/路灯/人物/房子/马车）→ SAM3 首轮抠关键元素 → 后续迭代给宽泛语义抠零碎内容（VLM 后续轮是否参与=中立待验，接口留复入位）。
3. **停止判据**：图层有效内容 ≈ 钻径量级（~5mm×5mm，钻 2-5mm）/ 图层颜色容差已低（天空草地类大范围内容）/ SAM3 自认不可拆（更佳）/ 最大迭代硬顶。
4. **产物=树状 object-tree**：每层 object-name + 归属关系（路灯=杆+灯）。
5. **贴钻必须多元化**——现行统一算法被定调为「毫无灵魂的工业品」：纹理贴图法（柳树顺枝条）、柔和曲线（布艺）、花形（花心花瓣）、直线（刚硬物）、几何（星形射线/心形/方形/圆形/矩形/椭圆/螺旋）、排除（不贴）、**自由代码片段**（大模型自写算法；环境注入类 OpenCV 能力；JS 大概率/Python 待调研——协调方首版倾向 JS 同进程沙箱）。
6. **LLM 基于-object-tree 设计策略**（可无视觉），可带艺术家风格出多版本候选（后话）。
7. **两层编辑铁律**：Agent 对话=策略层（图层级策略/参数，含人工调参，**不能动单钻**）；设计师工作台=单钻微调层。两种工作台地基（W0-W3 已建）为此而设。

与同日上午定调合流：原始流程（cm 尺寸→钻尺寸→主体→抠图→逐主体上钻→拼接）+ 中间产物=工具契约。

## What Changes

1. **识图管线（新）**：VLM 全图分析（经既有 LLM 路由）→ SAM3 迭代抠图（macmini 桥）→ 停止判据（确定性适配层计算）→ **object-tree 工件**（Scene Graph Elements[] 结构：id/category/label/mask/parent/children + 有效物理尺寸 + Lab 色容差）。
2. **策略面四类（新+重组）**：参数化几何（星射线等，纯 TS 参数模型）；语义拟合（纹理亮暗/柔和曲线/花形——拟合算法重、参数极简）；排除（节点开关）；**自由代码（JS 沙箱 worker，注入 mask/标度/钻规格/几何函数库，输出强制 Gem[] 过引擎校验门——最小间距/exportGate，确定性 seed 可回放）**。既有五策略（hex/poisson/hybrid/cvt）降为基础几何族成员。
3. **策略设计器（新）**：LLM 基于 object-tree+风格提示词生成每节点策略分配（proposal 工件，过授权桥审批）。
4. **Agent 策略层 UI（W4.3 重排）**：左对话右实时画布，图层树+每层策略/参数面板，图层级编辑。
5. **PhysicalCanvas(cm) 一等输入**：pixelsPerMm 推导（纵横比不符显式拒）。
6. **颜色结构自动分块=一键兜底**（现行路径保留）。

## Impact

- contracts：object-tree/策略 schema/代码策略工件；pave 参数扩展。
- daemon：macmini 桥（SAM3+可选 VLM）、JS 策略沙箱、策略注册表、LLM 策略设计器工具。
- rhinestone-studio：策略层 UI（左对话右画布）、object-tree 面板。
- 引擎：**零改动红线**——所有策略（含自由代码）输出 Gem[] 过引擎校验门。
- 既有地基复用：授权桥/会话/帧流（W0-W4.2）、设计师工作台单钻编辑、五策略引擎。
