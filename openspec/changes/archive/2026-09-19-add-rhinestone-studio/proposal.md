## Why

局部贴钻（Partial Drill）的核心难题不是"图片像素化"，而是"哪些区域值得成为钻位"的审美决策。样本实证（tech-research.md §1）表明真实作品的排布遵循"元素级二元掩码 + 全域恒定密度 + 六方错行密排"的可枚举公式，而现有工具生态全部只做全贴钻格子转换，无人做局部审美增强层。

用户此前用拼豆项目验证过两段式方法：不可靠的生成模型先做风格化（少色像素图），稳定程序再做确定性转换。本项目把同构方法用于贴钻：中间表示是"贴钻层数字油画"（少色、闭合面域、结构简化、氛围层剔除），生成模型承担全部决策（贴哪里/什么色/简化程度），程序只剩纯几何问题。

## What Changes

- 新建纯前端应用 `rhinestone-studio/`（Svelte 5 + shadcn-svelte + Vite 8 + Tailwind v4），BYOK 零后端。
- 模块 A「提示词实验室」（prompt-lab capability）：BYOK 设置 → 原图上传 → 提示词变体组（默认 5 组 × 2 候选，可编辑增删）→ 客户端并发生成 → 分组画廊 → 与原图叠加/并排预览 → 一键送转化。
- 模块 B「转化工作台」（layout-engine capability）：数字油画 → Lab 量化 + 连通域分块 → 每块密度独立可调 → 5 种排布算法（S1 六方+蓝噪声抽稀 / S2 pitch 调制 / S3 Poisson / S4 语义混合 / S5 CVT 点画）+ 2 个松弛钩子（边界 1D Lloyd、斥力修复）同屏对比 → Lab ΔE 颜色映射 → 硬约束校验 → SVG/BOM 导出。
- 转化引擎为纯 TS 深模块（不 import Svelte），vitest 覆盖几何不变量（最小间距、无重叠、钻数随密度单调）。

### Non-goals

- 不做后端服务、账号系统、部署流水线（纯前端 BYOK 直连，CORS 为接受成本）。
- 不做 SAM/VLM 意图层、AI 自动审美决策（Phase 2 后续 change）。
- 不做真实供应商色卡数字化校色（内置起步色板 + 用户手工编辑）。
- 不做方钻、多 SS 混排、切割模板工艺细节（SS 尺寸表内置但单尺寸全局）。
- 不训练任何自有模型。

## Capabilities

- `prompt-lab` — 提示词变体驱动的贴钻层数字油画生成、分组候选管理与预览
- `layout-engine` — 数字油画到合法钻位的分块、多算法排布、密度控制、校验与导出
