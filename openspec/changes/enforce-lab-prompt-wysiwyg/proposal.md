# Proposal: enforce-lab-prompt-wysiwyg — 提示词组合所见即所得（退场一切隐藏注入）

## Why

Owner 2026-09-21 发现并裁决（原话）：

> 提示词夹带私货，怎么会有一段："你是一位专业的钻石画……"不要这些，客观地，我在模板里面配置什么就是什么，所见即所得。
> 至于图一图二这些多图的介绍，应该纳入"案例参照图"的提示词中。而不是通过夹带私货来达成

事实定位（effectRefs.ts `composeDrillPrompt`）：现组合器向请求注入六层隐藏内容——①人设前言「你是一位专业的钻石画（Diamond Painting / Partial Drill）与水钻装饰设计专家。」；②「我上传了N张图片：1. 【图N [image #N]：角色】：…」图序声明块；③四变体任务指令行；④固定【贴钻指导规则】块（DRILL_RULES）；⑤用户模板正文被包裹为「【模板风格补充】：\n<正文>」；⑥结尾输出指令行。用户所配置的 promptBody 仅是六块之一，与所见即所得原则相悖。

## What Changes

1. **WYSIWYG 公理（新 byteEq 红线）**：三开关全关 + promptBody 无占位符 → 发送提示词 ≡ promptBody **逐字节**（无人设、无壳、无任务行、无规则块、无输出行）。
2. **六层注入全部退场**：人设前言/任务指令行/输出指令行/【模板风格补充】壳/计数行整体删除；组合器收敛为「占位符替换 + 附空缺省不动」。
3. **图序声明移入案例参照图片段**：多图介绍（图一 [image #1]=案例参照图…图二 [image #2]=原图…与简短参照任务句）由**案例参照图片段的默认（auto）内容**承载——按实际活跃附图集生成（案例开/关、复合对照/单图布局变体并入默认文案），用户在效果提示词 Dialog 中可见可改可清空；清空=不发送任何图序说明（用户的明确选择）。
4. **DRILL_RULES（固定贴钻规则）归宿〔裁断，可推翻〕**：并入 v2 模板 seed 正文尾部（可见、逐模板可编辑可删）——既有用户模板正文不动（自然失去注入，正是 WYSIWYG 语义）；不另设隐藏通道。
5. **蓝图提示词同原则**（composeBlueprintPrompt 的 BLUEPRINT_* 骨架同人退场，声明/任务句并入蓝图效果片段默认内容）。
6. **发起前终稿预览**：发起区提供「最终请求提示词」展开预览（替换后全文）——所见即所得的可验证面。

## Non-Goals

- 三开关/占位符体系本身（add-lab-effect-prompt-placeholders 与 improve-lab-advanced-ux 已定的正交结构与注入/移除交互不变——变的只是片段**默认内容**与组合器契约）
- 素材附图顺序逻辑（orderDrillImages 的实际附件排序不变——变的是「说明文案」的承载位置）

## Impact

- `lib/lab/prompt.ts`（组合器契约+figureTagOf 消费面收窄）、`lib/presets/effectRefs.ts`（六层注入退场+片段默认生成器扩展）、模板 seed 正文（v2 追加规则尾）、lab 管线接线、byteEq 基线第三次再生（新红线=旧输出作废）、RunBar 终稿预览、相关测试族。
