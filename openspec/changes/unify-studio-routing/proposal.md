# unify-studio-routing

## 为什么

Owner 指令（2026-10-04）：「切换到工作台/拍钻，路由没有变更——为什么这些页面不统一走路由层？还有什么残留的工作不要给我遗留了，好好处理。」

现状：studio 是单 App.svelte SPA，页面切换=组件态（src/lib/pages + views），全仓 20 处零散 `pushState/replaceState`，无统一路由层——工作台/拍钻等页面 URL 不变（不可收藏/不可回退/不可分享定位），部分页面又有 ad-hoc URL 写入（行为不一致）。

## 是什么

1. **统一路由层**：引入路由表（会话列表/任务详情各 tab/工作台/分享/admin 各区/设置），所有页面切换走路由（URL 可定位/可回退/可刷新还原）；清理 20 处零散 history 调用收编进路由层
2. **残留工作清理（Owner 点名「不要遗留」）——sweep 清单**：
   - 匿名进入按钮失效（token 已写但弹窗不关——T6a 发现）
   - rpc 模式入口不可发现（缺省 MOCK，需 ?api=rpc/登录——生产动线受阻）
   - 零检出态双文案语义相拗（「检出实例但未回 score」vs「零可用实例」并存）
   - tab 双高亮观感（焦点态+选中态并存）
   - 旧 bundle 过期审批卡（composer 残留 234c098b）
   - 任务详情打开导出后面板静默重绑（走查 minor）
   - 「用时 75222s」跨天口径（帧污染）
   - 图例贴图缩略（numbered.png 图例为色点）
   - daemon e2e 分享页文案漂移（http.ts「下载 PNG」vs 测试期望——存量）
3. 视图态与路由态边界规范（哪些进 URL 哪些留本地态——如混合滑杆位置不进路由）

## 不做什么

- 不改后端路由（/r/ 分享页/文件端点已 URL 化）
- 不动 8317 生产数据

## 验收口径（草案）

- 工作台/拍钻/任务详情每个 tab 切换 URL 变更且刷新/回退还原同状态（vision 走查）
- 全仓 pushState/replaceState 零散调用清零（收编路由层）
- sweep 清单逐项闭合作业（修复或显式挂账给 Owner 裁决）
