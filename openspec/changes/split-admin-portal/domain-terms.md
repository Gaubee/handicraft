# 贴钻工作台领域词汇

| 术语 | 统一含义 | 使用边界 |
|---|---|---|
| 前台 | 面向操作者的 Agent 工作区 | 会话、图片附件、Agent 反馈、审批和产物；不是“开发者模式” |
| 后台 | 同一应用内受 admin 角色保护的管理工作区 | 账号、模型/图像设置、知识库和资源治理；不是独立部署服务 |
| 会话附件 | 通过 `BlobRef` 关联到会话的图片或文件 | 引用须有 owner 校验和生命周期账本；BlobRef 本身不是授权凭据 |
| 素材库 | 可浏览、整理和复用的项目素材集合 | 区分用户私有与管理员维护的共享素材；浏览器 IndexedDB 不等于服务端真源 |
| 装饰钻库 | 钻型、尺寸、颜色等钻石资料目录 | 后台负责维护，Agent 通过受控 MCP 能力消费；不代表实物库存 |
| 组合库 / 套装库 | 由若干素材或钻型构成的可复用组合 | 当前对应 `sets` 领域；必须保留 owner/shared 归属 |
| 仓储 / 库存 | 真实物品数量、地点、批次及其变化记录 | 当前贴钻 `WarehouseView` 尚非此领域；实现前须单独定义库存实体和流水 |
| 知识库分组 | 一类有说明的领域知识目录 | 首版采用 Markdown 文件 + Git 历史，不要求向量化 |
| 知识条目 | 分组内可单独读取和修订的知识内容 | Agent 通过 MCP 按需读取；写入经持久提案与用户批准 |
| 模型路线 | 一个提供商的协议、Base URL、密钥和模型清单 | 由后台管理员维护；Agent 只读取可用模型，不读取密钥 |
