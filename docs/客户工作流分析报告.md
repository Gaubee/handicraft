# 客户 ComfyUI 工作流分析报告（2026-09-23）

依据：客户操作视频（2:42，vision 逐段判读）+ 输出图集 8 PNG/3 TIF（vision 像素级取证）+ SVG/XLSX 程序化解剖（本会话）。证据分级：视频观察 / 像素实测 / 文件解析。

## 1. 客户产品与工作流全貌

**产品形态**：珍珠/串珠绣风格的「钻石画（Diamond Art）」套装——**仿刺绣链状的自由曲线珠点排布**（非网格钻贴），25×25cm 交付（名义 30×30），约 2454 颗/图，10 色供应商色卡（A 系小珠 3.0mm + G 系大珠 10.0mm 混排）。

**运行环境**：OneThingAI 租用云 GPU（RTX-4090，¥0.1-0.13/h 按量，闲置自动关机），ComfyUI_v0.1.05 官方版；工作流「亮钻石画」（另有 CorelDRAW 向变体未演示）；**字库节点加密**（供应商防拷贝——此工作流是外购产品）。

**管线**（视频时间线+产物链合成）：
```
本地文件夹拖传云端 input/ → 手填参数（路径/钻径/尺寸/最大色数）→ 一键批量排队（~2min/图）
  每图全自动：载入 →（上游疑 AI 生成/重绘珠风底图）→ GPU 珠点检测（自由点位）
    → 分类编码（≤N 色 → 供应商色号 A52…A85；大珠 G 前缀）
    → 产物 11 文件：图例色卡 / QC 标注图 / 彩色珠渲染(透明底) / 编号工作图 / 黑点模板 /
       BOM 文本页 / 四层 SVG(原图+黑点+编号+贴图替换) / XLSX / 说明书 TIF×3
```

**下游**：CorelDRAW（印刷/后期，未演示）；上游：同实例装 SD1.5 文生图 + 旧实例的去水印/换背景/去文字预处理。

## 2. 与我们引擎的对照（差距清单）

| 能力 | 客户管线 | 我们现状 | 差距 |
|---|---|---|---|
| 底图生成 | AI 生成珠风图（SD 系） | 实验室 gpt-image（BYOK） | 路线不同，功能等价 |
| **珠点检测** | GPU 识别自由点位（沿刺绣曲线） | ❌ 无——我们假设网格排布 | **最大分叉**：逐珠自由点位 vs 格位排布 |
| 分色量化 | ≤N 色聚类→色号 | ✅ k-means+连通域（Lab ΔE） | 等价，但色号体系是**供应商色卡**（A/G 编码） |
| 混尺寸 | 3.0mm+10.0mm 逐珠混排 | 部分（逐钻直径可改，无混排策略） | 小 |
| 编号工作图 | ✅ 点内编号+图例（数字油画打法） | ❌ 无 | **导出形态缺口** |
| 四层 SVG | ✅ 原图/黑点/编号/贴图替换 | ✅ 单层钻点 SVG | 层结构缺口（易补） |
| BOM/XLSX | ✅ XLSX+文本页 | ✅ CSV（BOM） | XLSX 化小缺口 |
| 说明书 TIF | ✅ 三页印刷版式 | ❌ | 排版类，后置 |
| 交付一致性 | 25cm@300dpi 画布、BOM/点位对账严丝合缝 | ✅ 同等纪律 | 平手 |

## 4.5 修正注记（2026-09-23 晚，Owner 确证+配置采集）

- **画布**：视频为 20X20cm（「30x30」是此前输出包的名义规格——两单不同）
- **输入=普通卡通图（无珠子）**：推翻本文 §2「在珠风底图上检测」的推断——管线首段必含**语义检测/分割**（配置采集实锤：GroundingDINO SwinB/SwinT + SAM-2 + YoloWorld-EfficientSAM + segment_anything + BiRefNet + florence2 + 双 CLIP 文本编码器），即「在普通图上开放词汇识别主体/区域 → 生成沿轮廓的有机珠点」，而非珠点检测
- **四张输入原图**已存 ~/Downloads/20x20/（736×736 卡通，哈希名与视频一致）
- **环境**：实例是通用 AI 工作站（Joy_caption/Omnigen2/SEEDVR2/LLM 目录俱在）；字库加密节点=ComfyUI_Onething_Encrypted（平台加密机制）
- **工作流 JSON 缺采**：浏览器侧工作流不在 my_workflows（空），补采指令已更新（user/default/workflows）

## 4.6 工作流 JSON 解剖（终局·2026-09-23 补采）

- **管线是供应商黑盒**：两个工作流（亮钻石画/亮钻石画CDR）各仅 21 节点——可见面只有 6 个参数节点 + XueYuanFolderLoader/FolderSave（300DPI 导出）+ UniversalPreview，**全部算法封装在「学源节点组加密」单节点（54KB XY3 加密载荷）**——供应商「学源」的外购加密产品，不可也不应破解。**自研路线是唯一路线**（技术栈已由环境配置实锤：GroundingDINO/SAM-2/YoloWorld/florence2 语义检测系）。
- **尺寸谜底**：可见参数中「尺寸高x宽=20X20」与「画布尺寸=25X25」**并存**——设计区与画布是两个参数，规律=**画布=设计区+5cm 边距**（20→25；30x30 输出包=25 设计+5 边距，全部吻合）。此前三个标定矛盾中的画布问题解决；珠径 2.8（参数）vs 3.0（BOM）vs 3.5（反算）仍待客户口径。
- **完整参数面**（6 个）：输入文件夹/输出文件夹/钻径 2.8/最大色数 7/设计区高x宽/画布尺寸——这就是产品化后的参数表原型。

## 4.7 输入图质量闸门（vision 四图分析）

适合管线的输入=①单一主体+纯净近白底②色系 3-8 且色块大而整、对比高③主体内部纹理少（<2-3 钻宽的细元素会糊）④**无水印**（ebdc 图整图平铺水印=输入闸门问题）。四图适配排序：2a0c 小丑>5836 花束>f5c7 圣诞场景（细节过密+银白低对比）>ebdc 小矮人（水印+发丝）。**对我们实验室的启示：底图生成提示词应约束「少色系大色块、纯底、无细纹理」风格**。
