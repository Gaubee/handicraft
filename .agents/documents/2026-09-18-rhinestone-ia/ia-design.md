## 0. 产品模型定框（建议后续抽为仓库根 PRODUCT_MODEL.md）

仓库无 PRODUCT_MODEL.md，先在此定框，后续所有界面改动以本节为准：

**一句话**：两段式单向管线 —— 实验室产出「数字油画中间稿」，工作台把中间稿变成「可生产交付物（钻位 SVG + 采购 BOM）」。

**对象模型与单一真源**

| 对象 | 真源位置 | 生命周期 |
|---|---|---|
| BYOK 连接 | SettingsDialog（localStorage） | 手动配置，跨会话 |
| 参考原图（Lab） | Dropzone → lab store | 会话内，随任务 |
| 提示词变体组 | VariantEditor → lab store | 跨会话持久 |
| 候选任务 | TaskQueue（IndexedDB 存图） | 跨会话，可失效重生成 |
| 数字油画（Studio 入图） | handoff 或上传 → studio store | 会话内 |
| 分块/块覆写 | studio store（k/seed 重分块即清空覆写） | 随入图 |
| 排钻策略选择 | **必须唯一**：策略对比网格选中卡（当前存在双真源，见 B5） | 随会话 |
| 色板 | studio store | 跨会话 |

**双人分工**（决定收纳层级的关键证据）：
- 朋友（手艺人）：看候选哪张好看 → 看钻怎么排 → **要买多少钻**。不读英文 prompt，不碰 JSON。
- Owner（技术）：BYOK、prompt 变体、k/seed、Advanced JSON。
- 结论：界面必须让「看 + 判断 + 导出」在零配置知识下可完成；所有需要理解 API 概念的东西都可以收进二级空间。

## 3. 功能组织收纳（核心交付）

### 3.1 二八盘点

**20% 高频核心（应占 80% 视觉空间）**
- 实验室：上传原图、开始生成、候选画廊（对比/预览/送转化）
- 工作台：分块画布（选块）、块密度/禁用、五策略对比网格、钻数与导出

**80% 低频（收进间接空间）**
- BYOK 设置（一次配置）、Advanced JSON + 尺寸（逃生舱）、变体全文编辑（模板已预填，日常只微调）、色板编辑（初期定一次）、k/seed（偶尔重分块）、gap/SS（项目级物理常数）、debug 详情、块文字列表（画布是主选择器）

### 3.2 信息架构树（L0 常驻 / L1 上下文露出 / L2 收纳）

```
贴钻工作台
│
├─ 全局壳（两模块共享）
│   ├─ 顶栏：标题 │ 连接状态芯片[● gpt-image-2.5 / ○未配置→点击开设置]
│   └─ 移动端：底部 Tab ×2（实验室 / 工作台）
│
├─ ① 提示词实验室（产出中间稿）
│   ├─ L0 参考原图上传（Dropzone，保持现状）
│   ├─ L0 变体组「摘要行」：名称 + ×N 候选 + 首行 prompt 预览（手风琴，默认仅第 1 组展开）
│   ├─ L0 生成动作：左列底部 sticky「开始生成 ×N」（未配置 → 「配置连接」）
│   ├─ L0 任务画廊（右侧主区，现状保留）
│   ├─ L1 变体展开编辑（点摘要行展开：prompt textarea + 候选数 + 删除）

│
└─ ② 转化工作台（产出交付物）
    ├─ L0 分块画布（主区，高度自适应容器；工具条：适应/±/缩放%/分块中）
    ├─ L0 策略对比网格（主区，选中卡 = 导出策略唯一真源）
    ├─ L0 导出条：当前策略(只读) · 共 N 钻 · 校验徽标 · [SVG][BOM][PNG]

    ├─ L1 预览模式工具条（纯钻点/叠稿/叠原图 + 透明度；参考图随 handoff 自动带）
    ├─ L1 违规清单 + 修复建议（导出阻断时展开）
    ├─ L2 「物理参数」折叠组：SS / gap / 全局密度（含全局预估钻数）
    ├─ L2 色板：常驻色条 chips（色块+名称+用量），编辑器收进 Dialog
    └─ L2 「分块参数」折叠组：k / seed（带「重分块将清空块覆写」警示，现状已有文案）
        L2 块文字列表：折叠为「N 块 · M 禁用 ▾」摘要行（画布为主选择器，列表为无鼠标辅助）
```

### 3.3 容器收纳决策表

| 容器 | 形态 | 收纳理由（针对当前哪个控件） |
|---|---|---|
| 变体编辑器 | 手风琴（首组默认展开，余为摘要行） | 替代 VariantEditor 5 组全展开：模板已预填，日常只微调 1-2 组；朋友可不展开直接生成。摘要行保留「组数×候选数」使生成按钮的 ×N 可核对 |
| 高级请求参数（JSON+尺寸） | 折叠组，默认收起，非空时带● | 替代 VariantEditor L102-134 平铺：自述为「逃生舱」的功能就该按逃生舱收纳 |
| BYOK 设置 | Dialog（保留），入口从卡角 ghost 按钮升级为顶栏状态芯片 | 连接状态是全局事实（两模块都依赖），不该只存在于实验室卡片里；芯片点击=开 Dialog，未配置时芯片即冷启动 CTA |
| 物理参数（SS/gap/全局密度） | 折叠组 | 项目级常数，设定后数个会话不动；当前却是工作台左栏第 1 张卡 |
| 色板编辑器 | Dialog；画布侧常驻只读色条 chips（色块+名称+用量） | hex/name 编辑是初始 setup 行为；日常只需要「看到当前配色 + 块颜色覆写下拉引用它」 |
| 分块参数（k/seed） | 折叠组 + 破坏性警示 | 低频且重分块清空覆写（BlockPanel 描述已承认），破坏性低频操作必须显式展开后才可见 |
| 块文字列表 | 折叠摘要行「N 块 · M 禁用」 | 与画布双通道选择是冗余；保留给键盘/精确场景，默认折叠 |
| 块详情 | 视口内固定区域（选中即现，可自动 scrollIntoView） | 解决 #16「点了没反应」；精调是 80% 时间所在 |
| 策略选择 | CompareGrid 选中卡（加「✓ 导出策略」角标） | 单一真源；ExportBar 的 Select 移除，改只读回显 |

| 工作台·空 | 画布区大空态：两个入口（回实验室选 / 直接上传） | 全部参数折叠组 |

| 就绪 | 画布 + 策略网格（自动算）+ 钻数徽标 | — |
| 选中某块 | 块详情立即入视口 | 其他块详情收起 |
| 校验违规 | 违规清单 + 「开斥力修复 / 降密度」直达 | 导出按钮禁用 + 原因 |

### 3.5 三个争议问题裁决

**Q1 变体编辑器该不该常驻？**
不该以「全展开」常驻。对 Owner 它是核心工具但单次会话只精调 1-2 组 → 手风琴（一次展开一组）兼顾；对朋友它是障碍 → 摘要行可直接无视。生成动作 sticky 后，变体区长度不再影响主行动。判断依据：默认模板已可用 + 复用参数功能存在，两者都说明「逐字编辑不是每次的必经路径」。

**Q2 色板/分块参数/Advanced JSON 属于哪层？**
色板编辑 = L2 Dialog（常驻只读 chips）；分块参数 = L2 折叠组（破坏性+低频）；Advanced JSON+尺寸 = L2 折叠组（逃生舱自述）。三者共同点：理解它们需要 Owner 级知识，且都不在「看图 → 判断 → 导出」的视觉主路径上。

**Q3 全局 vs 块级的层级关系？**
倒置当前顺序：**块级（精调）为常驻主体，全局（物理常数）为折叠背景**。规则一句话：改一次管全局的收起来，改一次管一块的放在手边。全局密度的语义（「作用于未覆写的块」）在折叠组描述里保留现状文案即可。

## 4. 移动端策略

### 4.1 导航

- 底部 Tab Bar ×2（实验室 / 工作台），lg 以下替换顶栏 Tabs（顶栏 Tabs 在 375px 已拥挤，App.svelte ml-auto 布局）。
- 顶栏瘦身为：标题 + 连接状态芯片（点击开设置 Dialog，Dialog 在移动端为全屏 sheet）。

### 4.2 两模块的移动端形态

**实验室（可完整跑通）**：单列 = 顶栏 → 原图上传 → 变体摘要行（手风琴天然适配）→ sticky 生成按钮（吸底，位于底部 Tab 之上）→ 画廊 2 列网格 → 点卡全屏预览（叠加/并排保留，透明度滑杆加高命中区）→ 送转化。

**工作台（查看+轻调为主）**：单列顺序强制重排为「画布优先」：
```
载入摘要行(来源·尺寸·更换) → 画布(60vh) → 策略对比(carousel) → 导出条
参数入口 = 画布上方工具条: [块][物理][色板] 三个按钮 → 底部抽屉(bottom sheet)
选中块 → 半屏底部抽屉块详情（拖拽手柄可展开/收起）
```

### 4.3 画布与对比网格的降级

- 画布：单指平移（pointer 基础已有）+ **pinch 缩放（以双指质心为锚，补齐 zoomAt 的双指版）** + 双击适应；保留 ± 按钮。块命中阈值放宽（移动阈值 8px 内视为 tap）。
- 对比网格：桌面 5 卡同屏 → 移动端横滑 carousel（scroll-snap）：顶部策略 chips 横滑条 + 单张大图卡（钻数/耗时/合规徽标随卡）。理由：375px 下 5 张 240px 卡不可辨认，「同屏」降级为「快速翻页」；选中策略 = 当前停驻卡，与导出真源一致。

### 4.4 明确不做移动端（及理由）

| 不做 | 理由 |
|---|---|
| Advanced JSON 编辑 | 小屏写 JSON 不可行且高危（逃生舱属性，回桌面） |
| k/seed 调整 | 低频 + 破坏覆写 + 误触代价高；查看保留、编辑禁用并提示「桌面端调整」 |
| 色板 hex 批量编辑 | 初始 setup 行为，桌面完成；移动端只读 chips（单色替换可作 P2） |
| debug 详情 | Owner 诊断工具 |
| 双策略并排大图对比 | 屏宽不够，carousel 已覆盖「逐个看」 |
| 移动端导出 SVG/CSV 的完整校验清单 | 下载与展示可做，违规修复流程引导回桌面 |

判断依据：双人协作下，重决策与精调在桌面完成；手机的典型场景是「看结果 / 给朋友展示 / 下载 PNG」。所有「不做」都允许查看。

### 4.5 触控适配要点

- 滑杆（密度/gap/透明度）：轨道命中高度 ≥44px，两端步进按钮；数值实时大字回显。
- 画布：见 4.3；`touch-none` 保留（防页面滚动劫持），平移交给 pointer。
- 底部 Tab：48-56px + iOS 安全区 padding。
- 底部抽屉：拖拽手柄、半屏/全屏两档、背景点击关闭；块详情抽屉打开时画布保持可见（半屏）。
- 长按：P2，块长按 → 快捷菜单（禁用/只看此块）。
